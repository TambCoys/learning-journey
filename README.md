# Learning Journey

Percorso di studio di ~6 mesi (ottobre 2026 → aprile 2027) per consolidare Python, SQL ed Excel e arrivare a data engineering e cloud (Azure).
Gli esercizi e i progetti usano dati di calcio, NFL, Formula 1 e cinema.

## Struttura
| Cartella | Contenuto |
|---|---|
| `python/` | Esercizi e problem set (CS50P, Automate the Boring Stuff) |
| `sql/` | Query T-SQL su SQL Server (database F1, Serie A) |
| `excel/` | File di esercizio: formule, tabelle, pivot, Power Query |
| `progetti/` | Mini-progetti e progetti mensili |
| `diario.md` | Diario settimanale: cosa ho imparato, blocchi, cose da ripassare |

## Roadmap
- **Novembre**: fondamenta di Python, SQL ed Excel
- **Dicembre**: analisi dati (pandas, SQL avanzato, Power Query)
- **Gennaio**: statistica e machine learning
- **Febbraio**: data engineering (ETL, Docker, dbt, Prefect)
- **Marzo**: cloud Azure, certificazione DP-900
- **Aprile**: progetto finale end-to-end

## Strumenti
Python 3.12 (conda) · VS Code · Jupyter · SQL Server / SSMS · Excel · Git
